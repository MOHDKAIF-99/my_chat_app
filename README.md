# Secure Real-Time Chat Application

A feature-rich, dark-themed real-time chat application built with **Node.js**, **Express**, and **Socket.io**. It features room-based messaging, custom avatar pickers, voice note recording with interactive audio waveforms, video/file sharing, and live online user notifications.

---

## 🚀 Features

* **Real-Time Room Messaging:** Join isolated rooms using a Room ID and exchange messages instantaneously.
* **Online User Notifications:** Get instant notifications when a user enters your active room.
* **Voice Notes with Waveforms & Speed Control:** Record voice messages directly in the browser. Features interactive audio waveforms powered by **WaveSurfer.js** and variable playback speeds (`1x`, `1.25x`, `1.5x`, `2x`).
* **Profile Management:** Dynamic profile picture generation via DiceBear API, full profile image viewing, and inline editing for custom user avatars and usernames.
* **Media & File Sharing:** Send images, videos, and general document attachments up to **50 MB** with built-in preview/lightbox support.
* **Responsive Dark UI:** Modern, clean UI built with CSS flexbox, keyframe animations, and custom scrollbars.

---

## 🛠️ Tech Stack

* **Backend:** Node.js, Express, Socket.io
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6+)
